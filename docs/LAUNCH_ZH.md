# 发布文案与初期路线

## 可直接分享

把 MOSS-Image 搬上 MacBook 了：基于 PyTorch / Diffusers 做了 Metal/MPS 适配，
通过分阶段加载、提示词缓存和 FP16 推理，让 Apple Silicon Mac 可以在本地生成图片。
已放出 M1 Max 32GB 的真实出图和参数，附安装脚本与网页界面，欢迎试跑、反馈机型和提 issue。

仓库：https://github.com/EdwinjJ1/moss-image-mac

## 定位

面向想在 Mac 本地试用 MOSS-Image 的用户。模型和原始推理代码来自 OpenMOSS；
本项目维护 Mac 适配。宣传使用真实样图和完整参数，区分上游展示与 Mac 实测。

## 初期工作

1. 收集不同芯片与内存容量的成功、失败记录，更新兼容性表。
2. 补充冷提示词与缓存提示词、FP16 与 BF16 的同条件性能对照。
3. 优先处理首次安装、模型下载和内存不足的问题。
4. 根据反馈完善安装体验，再评估量化与更低内存支持。

每次更新附复现步骤和证据。Star 数量无法保证；优先让别人成功生成第一张图。
这份文案是发布素材，尚未代发到任何群或社区。
